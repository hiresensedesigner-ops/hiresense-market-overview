# HireSense Market Overview

Talent-market intelligence dashboard — interactive design prototype.

**Live:** https://hiresensedesigner-ops.github.io/hiresense-market-overview/

A single self-contained page: scope the market by industry, function, location,
period and named peer set, and every reading, chart and table on the page is
recomputed from that scope.

Figures are illustrative and generated for this demo. They are not live market
data and are not attributable to the companies named.
